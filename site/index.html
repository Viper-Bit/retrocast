Retro games, recompiled to native code

retrocast turns a game's machine code into C and builds it into a native program for your PC: NES, Game Boy, Genesis, Master System, Atari 2600 and Capcom's CPS-1 arcade board. Every recompiled game is checked cycle by cycle against a built-in emulator, so it plays exactly like the original.

How it works

From a game you own to a program that runs it natively.

1 · PLAYPlay in the built-in emulator

Drop any supported game on retrocast: the system is read from the file. Save states, gamepads, up to four players.

2 · RECOMPILETurn it into C

The kit recompiles the game's code to C and builds a native program, with only CMake and a C compiler installed.

3 · VERIFYChecked, cycle by cycle

The recompiled game runs in lockstep with the emulator: any difference is caught, so it plays exactly like the original.
