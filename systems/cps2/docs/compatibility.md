# CPS-2 compatibility

Test budget is 10 emulated seconds per set. Boot progress requires
two different non-uniform frames and a 68000 that remains running through
the budget. This probe does not verify title recognition or gameplay.

323 of 324 sets showed boot progress. The loader assembled the 323 complete sets and ran them with the shared QSound DSP. The separate `gigaman2` run stopped during ROM loading on its undumped MCU, before CPU execution or video.
