How games are tested

Each game runs on its own in the built-in emulator for a few hundred to a thousand frames, with Start pressed; its last frame is kept as the picture. Boots: it shows a picture and the CPU never stopped. Partial: it runs, but the screen stays blank (it may need a longer intro, a button, or hardware we lack). Not yet: it fails to load, or the CPU halts. This is an automatic start-up test, not a play-through, and it is not the recompiler's cycle-by-cycle check (that one is run on chosen games). A game's versions are its regions, revisions and clones; the failing ones are marked in its list.
